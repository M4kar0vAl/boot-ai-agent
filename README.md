# ИИ-агент CLI

CLI приложение, которое принимает промпт от пользователя и передает его LLM через OpenAI sdk и OpenRouter.

Агент может выполнять такие функции:
 - просмотреть содержимое директории
 - прочитать файл
 - выполнить python файл (с возможностью передать аргументы)
 - создать файл и записать туда содержимое (или перезаписать существующий)

Работа агента ограничена директорией `calculator`, которая используется для тестирования поведения ИИ-агента.

## Запуск

Перед запуском убедитесь, что у вас есть аккаунт [OpenRouter](https://openrouter.ai/) и API ключ, который нужно указать в файле `.env` в корне проекта (`OPENROUTER_API_KEY`). 

```shell
uv run main.py <prompt>
```

**Например:**
```shell
uv run main.py "how does the calculator render results to the console?"
```
